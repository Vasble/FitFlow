# FitFlow

Застосунок запису на групові тренування для мережі фітнес-клубів (2 зали, ~1200 клієнтів).

- **Призначення:** замінити ручний запис адміністратора через месенджер: бронювання місць, QR-код для турнікета, push-нагадування, історія відвідувань.
- **Тип системи:** Mobile (iOS/Android) + Web (кабінети адміністратора й тренера).
- **Автор:** Мінчук Роман, Варіант 3 «Фітнес-клуб».
