# FitFlow

**Застосунок запису на групові тренування для мережі фітнес-клубів.** Замінює ручний запис адміністратора через месенджер: клієнт бронює місце в застосунку, отримує QR-код для турнікета й push-нагадування. Для клієнтів, тренерів і адміністраторів клубу (2 зали, ~1200 клієнтів).

> **Статус:** ранній етап (Спринт 0–1). У репозиторії зараз документація й планування; код сервера та застосунків додається за дорожньою картою — див. [docs/lifecycle-roadmap.md](docs/lifecycle-roadmap.md).

## Можливості

- Реєстрація клієнта за номером телефону.
- Розклад групових занять на 2 тижні з кількістю вільних місць.
- Бронювання й скасування місця (скасування — не пізніше ніж за 2 год до початку).
- QR-код бронювання для проходу через турнікет (працює локально, без інтернету).
- Push-нагадування за 2 год до заняття.
- Абонементи й історія відвідувань клієнта.
- Кабінет тренера: список групи й відмітка присутності.
- Кабінет адміністратора: розклад і ліміти груп.

Тип системи: мобільний застосунок (iOS/Android) + веб-кабінети тренера й адміністратора.

## Встановлення / запуск

Отримати робочу копію репозиторію (документація доступна вже зараз):

```bash
git clone https://github.com/Vasble/FitFlow.git
cd FitFlow
```

Запуск сервера (планується; стек зафіксовано в [ADR-0002](docs/adr/0002-backend-aspnet-core-docker.md)):

```bash
cp .env.example .env      # локальні секрети; файл .env не комітиться
docker compose up --build
```

> Файли `.env.example` і `docker-compose.yml` ще не додані — цей розділ буде оновлено разом із першим робочим сервером.

## Приклад використання

Основний сценарій клієнта:

1. Клієнт відкриває розклад і обирає заняття з вільними місцями.
2. Натискає «Забронювати» — отримує номер бронювання, лічильник місць зменшується.
3. У застосунку з'являється QR-код бронювання.
4. У клубі клієнт підносить QR до турнікета — локальний модуль перевіряє бронювання й відкриває прохід (≤ 2 с).
