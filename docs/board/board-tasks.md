# Завдання 3. Дошка задач (ALM-інструмент)

**Обраний інструмент:** GitHub Projects — команда й так веде вихідний код у Git-репозиторії, тому дошка задач природно живе поряд із кодом, issues й pull request'ами, без потреби синхронізувати два окремі інструменти.

**Колонки (Kanban):** Backlog · To Do · In Progress · Review · Done.

Нижче — макет налаштованої дошки з перенесеними задачами (ілюстрація структури; реальна дошка налаштовується самостійно в GitHub Projects або Trello за цією ж структурою, з посиланням на неї в супровідному листі до звіту).
