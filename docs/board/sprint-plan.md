## Definition of Done для спринту

- усі задачі спринту мають статус Done на дошці;

- код пройшов Code Review щонайменше одним іншим членом команди;

- усі автотести (юніт- та інтеграційні) проходять успішно;

- немає відкритих критичних або блокуючих дефектів (мітка Bug із пріоритетом Critical/High);

- функціонал перевірено вручну за критеріями прийнятності AC-FR-01 і AC-FR-03-01/02;

- код злито (merge) в основну гілку без конфліктів;

- виконано розгортання на тестовому (staging) середовищі.
